# پوشهٔ کاریِ کارتابلِ ناظر

`scripts/supervisor/inspection.py pull|urgent` این‌جا می‌نویسد و **در git نیستند** (`.gitignore`): ممکن است
پیوست‌های خصوصیِ مالک را داشته باشند.

| مسیر | محتوا |
|---|---|
| `QUEUE.md` | برگه‌هایی که کارِ ناظر دارند (فوری‌ها اول) |
| `URGENT.md` | برگهٔ فوریِ برداشته‌شده |
| `shots/` | تصویرهای پیوست و «بعد» |
| `files/<شماره>/` | بایت‌های پیوست + متنِ کاملِ استخراج‌شده (`<id>.txt`) |
