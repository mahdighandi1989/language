# ایمپورتِ دسته‌ای درس — قالبِ فایل (نسخهٔ ۱)

**کجا:** فقط مدیر — منوی کناری «مدیریتِ کاربران» (`#/admin`) › بخشِ «📥 ایمپورتِ دسته‌ای درس».
**مراحل:** انتخابِ فایلِ `.json` ← پیش‌نمایش ← «پشتیبان‌گیری و اعمال» (اول یک فایلِ پشتیبانِ JSON از وضعیتِ فعلی دانلود
می‌شود، بعد ادغام) ← گزارش. ذخیره در Firestore چند ثانیه بعد انجام می‌شود؛ خطا با بنرِ قرمز بالای صفحه نشان داده می‌شود.

```json
{
  "format": "lebanese-lessons",
  "version": 1,
  "lessons": [
    {
      "sourceKey": "rita/03",
      "title": "3 - ریتا",
      "course": "ریتا",
      "order": 3,
      "summary": "خلاصهٔ کوتاه (اختیاری)",
      "archivedNotes": "## متنِ کاملِ درس به markdown\n\n| لبنانی | فارسی |\n|---|---|\n| شو اسمك؟ | اسمت چیه؟ |",
      "knowledge": {
        "vocabulary": [{ "term": "قهوة", "definition": "قهوه", "example": "بدّي قهوة" }],
        "phrases":    [{ "term": "كيفك؟", "definition": "حالت چطوره؟" }],
        "grammar": [], "verbs": [], "pronouns": [], "adjectives": []
      }
    }
  ]
}
```

| فیلد | الزام | قاعده |
|---|---|---|
| `format` / `version` | ✅ | دقیقاً `"lebanese-lessons"` و `1` |
| `sourceKey` | ✅ | یکتا و پایدار (مثلاً `rita/03`، `khansa/t1/04`، `series/<نام>/<قسمت>`). **کلیدِ جلوگیری از تکرار**: اجرای دوباره همان فایل چیزی اضافه نمی‌کند. پس از ایمپورت عوضش نکنید. |
| `title` | ✅ | قالبِ موجود: `"N - نام دوره"` یا `"ترم ۱ - درس ۴ - الخنسا"`. اگر درسی با همین عنوان **بدونِ** همین `sourceKey` هست (مثل «1 - ریتا» ِ فعلی)، «تداخل» است و **رد می‌شود**؛ درسِ موجود دست نمی‌خورد. |
| `archivedNotes` | — | متنِ کامل، دست‌نخورده (هیچ trim/خلاصه/Gemini). markdown: `#`، جدول با `|---|`، فهرست `*`/`-`/`1.`، `**پررنگ**`، `*کج*`، `` `کد` ``، `>` نقل، خطِ تنهای `---` = جداکنندهٔ بخش. |
| `course` | — | نامِ دوره برای فیلتر (وگرنه از بعد از آخرین « - » ِ عنوان). |
| `order` | — | عدد برای ترتیب داخلِ دوره (وگرنه ترتیبِ طبیعیِ عنوان؛ ۲ قبل از ۱۰). |
| `summary` | — | رشته. |
| `knowledge.<دسته>` | — | دسته‌ها فقط: `vocabulary`، `phrases`، `grammar`، `verbs`، `pronouns`، `adjectives`. هر آیتم `term` و `definition` (رشته)؛ فیلدهای دیگر نگه داشته می‌شوند. تکراری (همان term در همان دسته، بی‌حساسیت به حروف) رد می‌شود. `source` اگر نباشد «درس: <عنوان>» می‌شود. |

حداکثر ۲۰۰۰ درس در یک فایل. فایلِ نامعتبر هیچ تغییری نمی‌دهد و فهرستِ خطاها را نشان می‌دهد.

**ذخیره‌سازی:** متنِ هر درسِ ایمپورتی جدا از سندِ اصلی ذخیره می‌شود
(`artifacts/{appId}/users/{uid}/lessonBodies/{key}` + `chunks/{i}`، هر تکه ≤ ۲۵۰هزار نویسه، با یک batch ِ اتمیک) و پس از ورود در
پس‌زمینه بارگذاری می‌شود؛ تا بارگذاری نشده، ویرایشِ متنِ آن درس قفل است. سندِ اصلی فقط ارجاع نگه می‌دارد. پیش‌نمایش حجمِ
سندِ اصلی پس از ایمپورت را نشان می‌دهد و بالای ۹۰۰KB اعمال نمی‌کند (دانشِ خیلی زیاد هم در سندِ اصلی است).
`firestore.rules` تغییری لازم ندارد (`users/{uid}/{document=**}` همین مسیر را پوشش می‌دهد).
